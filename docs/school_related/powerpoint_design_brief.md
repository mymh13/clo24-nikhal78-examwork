# PowerPoint Design Brief för Copilot

**Designstil: Mörkt tema med turkis accentfärg**

**Bakgrund:**
- Gradient bakgrund: diagonal gradient från mörkgrå (#2d2d2d) till nästan svart (#1a1a1a)
- Gradient-riktning: 135 grader (diagonal från övre vänster till nedre höger)
- Alternativt: solid mörkgrå bakgrund (#1e1e1e) för enklare slides

**Primärfärg (Accent):**
- Turkis/cyan: #4ec9b0
- Använd för rubriker, viktiga element, knappar och accentlinjer
- Text-shadow med ljus turkis glöd för rubriker

**Textfärger:**
- Huvudtext: ljusgrå (#e0e0e0)
- Sekundärtext: grå (#d4d4d4)
- Muted text: mörkgrå (#a0a0a0)
- Rubriker: turkis (#4ec9b0) med subtil glöd-effekt

**Typsnitt:**
- Primärt: Segoe UI
- Alternativ: Tahoma, Geneva, Verdana, sans-serif
- Rubriker: fetstilt (600 weight)
- Storlek: läsbar, minst 18pt för body text

**Layout & Komponenter:**
- Centrerad text för titlar, vänsterjusterad för innehåll
- Mörka kort/containers (#1e1e1e eller #2d2d2d) med turkis vänsterkant (3px border)
- Rundade hörn (6-8px border-radius)
- Generös whitespace mellan element

**Knappar/CTA:**
- Gradient-knappar: turkis (#4ec9b0) till mörkare turkis (#3aa895)
- Mörk text på knappar (nästan svart)
- Box-shadow med turkis glöd
- Rundade hörn (6px)

**Övrigt:**
- Minimalistisk, modern design
- Subtila skuggor och glöd-effekter
- Hög kontrast för läsbarhet
- Professionell, teknisk känsla

**Exempel på färgkombinationer:**
- Framgång/positivt: turkis (#4ec9b0) på mörk bakgrund
- Fel/negativt: ljus röd (#ff6b6b) på mörkröd bakgrund (#3a1e1e)
- Info: grå (#888) på mörkgrå bakgrund (#2d2d2d)
